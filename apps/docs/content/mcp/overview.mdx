# MCP overview

MCP (Model Context Protocol) lets an assistant call tools against your real data instead of guessing at it. Envpilot runs a remote MCP server, so Claude, Claude Code, Codex or Cursor can work with your projects' variables, secret files and shared accounts, with the same permissions, rate limits and audit trail as the dashboard.

Available on every plan, including Free (`mcp_server`). Connect by [signing in](/mcp/setup) with your Envpilot login. The old key-based setup lives on [API keys (legacy)](/mcp/api-keys).

```
https://www.envpilot.dev/api/mcp
```

Transport is Streamable HTTP. Auth is an OAuth access token from the Envpilot sign-in.

## What an agent can do

| Can                                                                   | Cannot                                            |
| --------------------------------------------------------------------- | ------------------------------------------------- |
| List the projects you can see                                         | Delete anything                                   |
| Read variables, secret files and shared accounts you can read         | Read outside your role's projects or environments |
| Create variables, files and accounts; update variables; replace files | Write a protected environment without approval    |
| Search project names and variable **keys**                            | See variable **values** through search            |
| Read and write documentation **drafts**                               | Publish a page                                    |

The agent does what your role allows, nothing more. A write into a [protected environment](/platform/protected-environments) becomes a change request that a second person approves, and documentation stays a draft until a person publishes it.

## Getting connected

1. [Add the server](/mcp/clients) to Claude, Claude Code, Codex, Cursor or VS Code, with no `Authorization` header.
2. [Sign in](/mcp/setup) when your browser opens.
3. Confirm with `/mcp` that the **tools** loaded, not merely that the server is listed.

## Limits

- **Available on every plan, including Free**, and re-checked on every call, so a platform admin turning the surface off for a tier stops the agent immediately.
- **A connection acts as you.** Your role decides what it sees; there is no way yet to give it less.
- **Rate limits apply per person**: 120/min metadata, 30/min value pulls, 30/min variable and account writes, 20/min file uploads. See [Tools](/mcp/tools#cost-of-each-call).
- **Every value-returning call and every write is audited** against your user.
