# MCP overview

MCP (Model Context Protocol) lets an assistant call tools against your real data instead of guessing at it. Envpilot runs a remote MCP server, so Claude, Claude Code, Codex or Cursor can look up your projects and read the variables your role allows, with the same permissions, rate limits and audit trail as the dashboard.

Requires the **Pro** plan (`mcp_server`). Connect by [signing in](/mcp/setup) with your Envpilot login. The old key-based setup lives on [API keys (legacy)](/mcp/api-keys).

```
https://www.envpilot.dev/api/mcp
```

Transport is Streamable HTTP. Auth is an OAuth access token from the Envpilot sign-in.

## What an agent can do

| Can                                        | Cannot                                            |
| ------------------------------------------ | ------------------------------------------------- |
| List the projects you can see              | Create, edit, or delete variables or files        |
| Read the variables your role can read      | Read outside your role's projects or environments |
| Search project names and variable **keys** | See variable **values** through search            |
| Read and write documentation **drafts**    | Publish a page                                    |

The agent reads and drafts; people change secrets and publish. Shared accounts, secret files and variable requests are not available over MCP.

## Getting connected

1. [Add the server](/mcp/clients) to Claude, Claude Code, Codex, Cursor or VS Code, with no `Authorization` header.
2. [Sign in](/mcp/setup) when your browser opens.
3. Confirm with `/mcp` that the **tools** loaded, not merely that the server is listed.

## Limits

- **Pro plan only**, re-checked on every call — a downgrade stops the agent immediately.
- **A connection acts as you.** Your role decides what it sees; there is no way yet to give it less.
- **Rate limits apply per person**: 120/min metadata and 30/min value pulls.
- **Every value-returning call is audited** against your user.
