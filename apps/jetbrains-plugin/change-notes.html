0.1.6

  • Pulled values are quoted on write, so newlines, hashes and quotes no longer corrupt the env file or escape the editor cloak.
  • Every background scope and global editor hook is tied to the plugin's lifetime; dynamic unload and reload are clean.
  • The tool window refreshes on sign-in, sign-out and every sync. Sync status and the sync lock are per project.
  • The organization tier gate now covers reveal and request actions. Session changes are serialized and a rotated token is never refreshed twice.

0.1.5

  • The plugin now honours the organization tier gate: an owner who disables JetBrains access stops new links and sync cycles, and the tool window says so.

0.1.4

  • Marketplace verifier clean on every supported IDE: no internal API, no scheduled-for-removal and no deprecated platform calls.
  • Sign-in uses the AuthKit device flow: a code in your browser, no loopback port, no admin configuration.
  • Startup runs on the background post-startup extension point, so project opening stays fast.
  • Cleaner tool window tree, Open Dashboard action, and richer settings: cloaking, hover, conflict resolution, auto-unsync and commit guard controls.
  • Switch Account uses a native chooser popup, and gutter markers expose accessible names for screen readers.

0.1.1

  • Token parsing fixed for WorkOS snake_case responses; sign-in now completes after browser approval.

0.1.0

  • Initial public release: link directories, pull variables and secret files, real-time sync, value cloaking, clipboard guard, drift detection, variable requests and the git commit guard.
